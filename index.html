📖 アプリの使い方ガイド

1. 基本的な使い方（過去問演習）

このアプリは技術士第一次試験（専門［衛生工学部門］・基礎・適性の3科目）の過去問を効率よく学習するためのツールです。画面上部の「専門／基礎／適性」のタブで科目を切り替えます。科目ごとに学習記録や成績グラフが分かれます。

  • フィルター機能: 「年度」「大分類」「小分類」「出題論点（細目）」「優先度」から解きたいジャンルを絞り込めます。
  • 問題の図・表: 図や表が必要な問題には、問題文の下に原本の画像が自動で表示されます。それ以外の問題も「📄 原本画像を見る」で試験問題そのままの画像を確認できます。
  • ブックマーク: 問題画面の ☆ を押すと登録できます（過去問・AI生成問題・腕試しの問題、腕試しの結果一覧からも）。スタート画面の「★ ブックマークを見る」で見返したり、ブックマークした問題だけを解いたりできます。
  • 操作のコツ: スタート画面の「出題する問題」「出題数」はボタン1つで切り替えられます。問題画面では、下の「◀ 前」で前の問題に戻れ、キーボードでは 1〜5=選択 / Enter・→=次へ / ←=前へ / B=ブックマーク が使えます。スマホの戻るボタンでも、進捗を保存してスタート画面に戻れます（腕試し中は確認が出ます）。結果画面の「間違えた問題をもう一度解く」で復習できます。文字の大きさは「⚙️ 設定」で変えられます。
  • ブックマークの活用: ブックマーク画面で、復習状況（未着手→復習中→克服済み）の切替、メモ、検索、状況での絞り込みができます。ブックマークした問題は、解くと自動で状況が更新されます（間違えたら復習中、2回連続正解で克服済み）。「📤 Notion・ファイルに書き出す」で、CSV（Notionのデータベース用）やMarkdown（Notionのページに貼り付け）を作れます。設定の「学習データのバックアップ」で全データを保存・復元できます。
  • Notionへの自動反映: ブックマークや間違えた問題を、Notionのデータベースへ自動で反映できます。準備と使い方は、下の「5. Notion連携」を見てください。
  • 腕試しのPDF出力: 腕試しの設定画面の「📄 この出題セットを問題冊子PDFにする」（過去問セット）、試験中の「📄 PDF」、採点後の「📄 解答・解説つきPDF／問題冊子・解答用紙のPDF」から、試験のような体裁（表紙・注意事項・問題・解答用紙・解答解説）のPDFを作れます。出力画面で「PDFとして保存」を選んでください。
  • AI問題セットの先行生成: 腕試しの設定画面でAI問題セットを選ぶと、裏で問題を先に作り始めます（「✅ 準備ができています」と出たら、すぐに開始できます）。試験を始めると、次回用のセットを自動で作っておきます。作った問題はこの端末に最長14日間保存されます。
  • 解説は後から作られます: 問題を速く作るため、AI問題の詳しい解説は、問題を解いている間に裏で作ります。腕試しでは試験中に作られ、採点のころには揃っています。網羅特訓で、答えた直後にまだ解説が届いていないときは、短い根拠が出て、数秒後に詳しい解説に切り替わります。
  • 同じ問題の重複を避ける: AIが出した問題は、この端末に記録されます（問題文と、問うている知識）。次に作るときは、記録にある問題と、問題文や知識が似ているものを除き、AIにも「これらは出さない」と伝えます。腕試しと網羅特訓で共通です。記録は設定の「AIの出題記録をリセットする」で消せます。
  • AI問題の品質チェック: AIが作った問題は、「誤りが2つある」「正解が一つに決まらない」といった問題を避けるため、別のAI呼び出しで正解を知らない状態から解き直して確認し、食い違う問題を除きます（設定でオフにもできます。オフだと速くなりますが、質が下がることがあります）。
  • 弱点克服フィルター: 「未回答の問題」や「過去に間違えた問題」だけを優先して出題し、効率的な復習が可能です。
  • 傾向重視: 出題順序を「傾向重視」にすると、近年よく出題されるテーマが優先的に出題されます。

2. AI機能・腕試しモードについて

このアプリの最大の特徴は、Googleの生成AI（Gemini）を活用して「過去問と似た傾向の新しいオリジナル予想問題」を作成できる点です。また、問題の解説をさらに詳しくAIに質問することもできます。

  • AI予想問題 網羅特訓: 選択したジャンルの過去問を分析し、新しい5択問題を自動生成します。
  • 腕試しモード: 本番と同じ形式・制限時間の模擬試験です。50%以上の正解で合格ライン。
    ・専門: 35問から25問を選んで解答（120分）。
    ・基礎: 5群×6問から各群3問ずつ計15問を選んで解答（60分）。
    ・適性: 15問すべてに解答（60分）。
    ・基礎・適性もAI予想問題（全問新作／AI＋過去問）で本番と同じ構成の模試を作れます。過去問ミックス・年度指定はAPIキー不要です。
    ミックスとAI出題では、同じテーマの問題が1回の試験に重ならないようにし、直近の腕試しで出た問題・テーマは出にくくなります（記録は腕試しの設定画面でリセットできます）。専門・基礎では、試験後に「選ばなかった問題」も解くと、選び方が最適だったか（何点取れていたか）を確認できます。
※AI機能（詳細解説・予想問題・腕試しモードのAI出題）を利用するには、ご自身で「APIキー」を取得してアプリに設定する必要があります（無料）。詳しくは下記の手順をご覧ください。

🔑 3. Gemini APIキーの取得と設定方法

AI機能を使うための鍵（APIキー）をGoogleから取得します。取得は無料で、数分で完了します。

  1. Googleアカウントにログインした状態で、以下のサイトにアクセスします。
    👉 Google AI Studio (API取得ページ)
  2. 画面内の 「Create API key」 または 「Get API key」 というボタンをクリックします。
  3. 新しいプロジェクトを作成するか選択し、APIキーを生成します。
  4. 生成された 長い文字列（APIキー） をコピーします。
  5. このアプリの「スタート画面」の一番下にある 「⚙️ AIモード用設定」 の入力欄に貼り付け、「保存」ボタンを押します。

※ APIキーはあなたの端末内（ブラウザ）にのみ安全に保存され、外部のサーバーには送信されません。
※ Google Gemini APIの無料枠は非常に大きいため、個人での学習用途で課金されることは実質ありません。

💾 4. 学習データの保存について

あなたの学習履歴（総正解数、各問題の正誤、腕試しの履歴、APIキーなど）は、お使いの端末のブラウザ内（ローカルストレージ）に自動的に保存されます。

  • ページを更新（リロード）したり、アプリのHTMLファイルを新しいものにアップデートしても、データは消えずに引き継がれます。
  • 【注意】 ブラウザの「閲覧履歴やCookieをすべて消去する」操作を行うとデータが消えてしまいます。また、別の端末（PCからスマホなど）や別のブラウザアプリで開いた場合は、データは共有されません。

☁️ 5. Notion連携（ブックマーク・間違えた問題）

ブックマークした問題と、間違えた問題を、Notionで後から見返せます。方法は2つあります。

  • A. 書き出して取り込む（設定不要・無料）: 「ブックマーク」または「間違えた問題」の画面で「📤 Notion・ファイルに書き出す」を開きます。
    • Notion用CSVを保存 → Notionの左メニュー「インポート」→「CSV」。検索・絞り込みできるデータベースになります。
    • Markdownをコピー → Notionのページに貼り付け。数式も変換されます。
  • B. 自動で反映する（最初に設定が必要）: 問題をブックマークしたり、復習状況・メモを変えたり、間違えたりすると、数秒後にNotionのデータベースへ自動で反映されます（アプリ → Notion の一方向。オフラインのときは、オンラインに戻ってから反映）。

自動反映の準備（一度だけ）（詳しい手順はリポジトリの worker/README.md）

  1. Notionで「ブックマーク問題」「間違えた問題」の2つのデータベースを用意します（列名は、書き出すCSVと同じ）。
  2. Notionの「インテグレーション」を作り、2つのデータベースに「接続」します。
  3. 無料のCloudflare Workers（中継サーバー）に、worker/notion-sync.js を置き、Notionのシークレット・同期キー・データベースIDを登録します。
  4. アプリの「⚙️ 設定・データ管理」→「☁️ Notionへ自動で反映」に、WorkerのURLと同期キーを入力します。「自動で反映する」をオンにして「保存」し、「接続テスト」を押します。

反映される内容

  • ブックマーク: 問題文・選択肢・正解・解説・メモ・復習状況（未着手／復習中／克服済み）・登録日・まとめノートへのリンクなど。
  • 間違えた問題: 間違えた回数・状況（未克服／克服済み）・連続正解・最後に間違えた日・あなたの回答など（「間違えた問題も反映する」で切替）。
  • 「今すぐ全件」を押すと、すでにあるデータをまとめて送れます。

知っておくこと

  • 同期の向きはアプリからNotionへの一方向です。Notion側で編集した内容は、アプリには戻りません。アプリで同じ問題を次に変更すると、その問題の行は上書きされます。
  • 「問題ID」の列は、アプリとの照合に使うので、Notionで消さないでください。
  • 「ブックマークを外したら、Notionのページもゴミ箱へ移す」をオンにすると、外した問題のページをゴミ箱へ移します（Notionのゴミ箱から復元できます）。初期値はオフです。
  • 同期キーは、この端末のブラウザにだけ保存されます。バックアップファイルには含まれません。
  • 失敗したときは、設定画面にエラーが出て、自動で再試行します。「接続テスト」で、原因（キー違い・データベース未接続など）を確認できます。
  • Notionの「学習ハブ」ページに、2つのデータベースへのリンクとアプリへのリンクをまとめておくと便利です。
