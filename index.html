📖 アプリの使い方ガイド

1. 基本的な使い方（過去問演習）

このアプリは技術士 衛生工学部門の過去問を効率よく学習するためのツールです。

  • フィルター機能: 「年度」「大分類」「小分類」「出題論点（細目）」から解きたいジャンルを絞り込めます。
  • 弱点克服フィルター: 「未回答の問題」や「過去に間違えた問題」だけを優先して出題し、効率的な復習が可能です。
  • 傾向重視: 出題順序を「傾向重視」にすると、近年よく出題されるテーマが優先的に出題されます。

2. AI機能・腕試しモードについて

このアプリの最大の特徴は、Googleの生成AI（Gemini）を活用して「過去問と似た傾向の新しいオリジナル予想問題」を作成できる点です。また、問題の解説をさらに詳しくAIに質問することもできます。

  • AI予想問題 網羅特訓: 選択したジャンルの過去問を分析し、新しい5択問題を自動生成します。
  • 腕試しモード: 本番と同じく「35問中から25問を選んで解答」し、制限時間付きで受ける模擬試験です。50%以上（13問以上）正解で合格ライン。出題は標準の「AI予想問題 35問すべて新作」のほか、AI予想＋過去問、過去問ミックス・年度指定（APIキー不要）から選べます。試験後に「選ばなかった問題」も解くと、選び方が最適だったか（何点取れていたか）を確認できます。
※AI機能（詳細解説・予想問題・腕試しモードのAI出題）を利用するには、ご自身で「APIキー」を取得してアプリに設定する必要があります（無料）。詳しくは下記の手順をご覧ください。

🔑 3. Gemini APIキーの取得と設定方法

AI機能を使うための鍵（APIキー）をGoogleから取得します。取得は無料で、数分で完了します。

  1. Googleアカウントにログインした状態で、以下のサイトにアクセスします。
    👉 Google AI Studio (API取得ページ)
  2. 画面内の 「Create API key」 または 「Get API key」 というボタンをクリックします。
  3. 新しいプロジェクトを作成するか選択し、APIキーを生成します。
  4. 生成された 長い文字列（APIキー） をコピーします。
  5. このアプリの「スタート画面」の一番下にある 「⚙️ AIモード用設定」 の入力欄に貼り付け、「保存」ボタンを押します。

※ APIキーはあなたの端末内（ブラウザ）にのみ安全に保存され、外部のサーバーには送信されません。
※ Google Gemini APIの無料枠は非常に大きいため、個人での学習用途で課金されることは実質ありません。

💾 4. 学習データの保存について

あなたの学習履歴（総正解数、各問題の正誤、腕試しの履歴、APIキーなど）は、お使いの端末のブラウザ内（ローカルストレージ）に自動的に保存されます。

  • ページを更新（リロード）したり、アプリのHTMLファイルを新しいものにアップデートしても、データは消えずに引き継がれます。
  • 【注意】 ブラウザの「閲覧履歴やCookieをすべて消去する」操作を行うとデータが消えてしまいます。また、別の端末（PCからスマホなど）や別のブラウザアプリで開いた場合は、データは共有されません。
