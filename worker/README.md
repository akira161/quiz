# ブックマークのNotion自動反映（中継サーバーの作り方）

アプリのブックマーク（追加・復習状況・メモの変更）を、Notionのデータベースへ自動で反映します。
向きは **アプリ → Notion の一方向** です（Notion側で編集した内容はアプリには戻りません。アプリで次に変更したとき、その問題の行は上書きされます）。

静的サイト（GitHub Pages）のアプリはNotion APIを直接呼べないため、無料のCloudflare Workersに小さな中継サーバーを置きます。Notionのトークンはこの中継サーバーだけが持ちます。

## 1. Notionのインテグレーションを作る
1. https://www.notion.so/profile/integrations を開き、「新しいインテグレーション」を作成（種類: 内部、対象のワークスペースを選ぶ）。
2. 機能は「コンテンツを読み取る」「コンテンツを挿入」「コンテンツを更新」にチェック。
3. 表示される **インテグレーションシークレット**（`ntn_…` または `secret_…`）を控える。
4. ブックマーク用データベース「ブックマーク問題（技術士一次試験）」を開き、右上「…」→「接続」→ 作ったインテグレーションを追加する。

## 2. Cloudflare Workers にデプロイする
ダッシュボードだけで行う方法（コマンド不要）:
1. https://dash.cloudflare.com （無料アカウント）→ 「Workers & Pages」→「作成」→「Worker」→ 名前を付けてデプロイ。
2. 「コードを編集」で中身を、このフォルダの `notion-sync.js` の内容に置き換えて「デプロイ」。
3. 「設定」→「変数とシークレット」に次を登録する。
   | 名前 | 種類 | 値 |
   |---|---|---|
   | `NOTION_TOKEN` | シークレット | 手順1のシークレット |
   | `SYNC_KEY` | シークレット | 自分で決める長いランダム文字列（例: `openssl rand -hex 24` の出力） |
   | `NOTION_DATABASE_ID` | 変数 | データベースのID（データベースのURLの末尾32文字） |
   | `NOTION_MISTAKES_DATABASE_ID` | 変数 | 「間違えた問題」データベースのID（使う場合のみ。`wrangler.toml` に記載済み） |
   | `ALLOWED_ORIGIN` | 変数 | `https://akira161.github.io` |
4. WorkerのURL（`https://〇〇.△△.workers.dev`）を控える。

GitHub連携（Workers Builds）でデプロイする場合: 「設定」→「ビルド」で **ルートディレクトリを `worker`** にし、デプロイコマンドは `npx wrangler deploy` のままにします。`worker/wrangler.toml` の `name`（`quiz`）を、Cloudflare上のWorker名と同じにしてください。`NOTION_TOKEN` と `SYNC_KEY` はビルド変数ではなく、Workerの「変数とシークレット」にシークレットとして登録します。

wranglerを使う場合は、このフォルダで `npx wrangler secret put NOTION_TOKEN`、`npx wrangler secret put SYNC_KEY`、`npx wrangler deploy`（`wrangler.toml` に変数を記載済み）。

## 3. アプリに設定する
スタート画面 →「⚙️ 設定・データ管理」→「☁️ Notionへ自動で反映」に、WorkerのURLと `SYNC_KEY` を入力し、「自動で反映する」をオンにして「保存」→「接続テスト」。
「今すぐ全件」で、すでにあるブックマークをすべて送れます。以降はブックマークを変更するたびに、数秒後に自動で反映されます（オフライン時は、オンラインに戻ってから）。

## 仕様と注意
- 問題ID（「問題ID」列）でページを照合し、無ければ作成、あれば更新します。Notion側で「問題ID」列を消さないでください。
- 「ブックマークを外したら、Notionのページもゴミ箱へ移す」をオンにすると、外した問題のページをゴミ箱に移します（Notionのゴミ箱から復元できます）。既定はオフです。
- ページの本文（問題・選択肢・正解・解説）は作成時だけ書きます。後からの更新はプロパティ（復習ステータス・メモなど）だけを書き換え、本文には触れません。
- `SYNC_KEY` を知らない人はWorkerを使えません。キーはこの端末のブラウザにだけ保存され、バックアップファイルには含まれません。
- Cloudflare Workersの無料枠（1日10万リクエスト）で十分に収まります。Notion APIは毎秒約3件の制限があり、Workerが自動で間隔をあけます。
- 1回の同期で送る件数は20件ずつです（多い場合は自動で分割）。

## 間違えた問題の反映
「間違えた問題（技術士一次試験）」データベースにも、同じインテグレーションを「接続」してください。アプリの設定で「間違えた問題も反映する」をオンにすると、ブックマークと同じ仕組みで、間違えた問題（回数・状況・最後に間違えた日・あなたの回答など）が自動で反映されます。
